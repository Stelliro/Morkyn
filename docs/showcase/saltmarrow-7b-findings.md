# Saltmarrow on Qwen2.5 7B: 100 turns, findings

The same setup as the Saltmarrow teaser (docs/showcase/saltmarrow-setup.json), with Qwen2.5 7B Instruct (Q4_K_M, data/mle-models) as the GM through MLE and an agent (Claude) as the player, after the Saltmarrow fix batch (#100-#122). Harness: tools/api_bridge_playtest.py --local-model. All data isolated in a scratch directory.

Run 3 is the 100-turn run: 100 turns, 0 fallbacks, mean 15.5 s per turn (median 12.0 s, max 56.25 s) on an RTX 4070 Ti. Runs 1 and 2 were stopped early to fix bugs that would have spoiled the rest (a teleporting MOVE; the pack emptied by unshown TAKE ops); those fixes are commits b474397 and bded3c6. Metrics: saltmarrow-7b-metrics.json. Issues filed as docs/PLAYTEST_ISSUES.md #123-#140, with reopen notes on #73, #78, #89, #97, #102, #122.

What held up: accepting a job by signing or saying so (#114), go-with (#115), level-up from XP (#121), sleep and typed rest healing and recovering (#119, #120), coins handed over counted into the purse, unshown losses refused, unasked takes refused, and no persuasion roll on plain questions (#89).


Run 1 (saltmarrow-7b-abort1) stopped at T5 to fix the move/grant bugs below (commit b474397: named is not reached; coin grants -> purse; salvage noun not a take). Run 2 restarted from T0 on that code.
