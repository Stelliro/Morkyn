Welcome · first run

Before you build a world

The settings can look a little confronting at first — lots of knobs, locks, and options. We designed them for simple controls: change what you care about, leave the rest alone, or hit Randomize and then only edit what bothers you.

That said: these settings matter. Genre, tone, death rules, how NPCs behave, magic, and checks all teach the model what kind of story this is. You’re not filling paperwork for its own sake — you’re shaping how the world will play.

The next screens walk each important control with a spotlight. Take your time — use Back anytime.

Powers

Optional starting abilities. Base text is locked once play begins.

Powers None · open to set count range and abilities ▾

Add none, one, or several abilities. Per-card Locked + prerequisites cover learned vs starting powers. Growth type per card; Calculate level-up math fills numbers from world/difficulty. Final math also refreshes at Start.

Randomize ability count –

1–4 skills. When count is unlocked, Randomize Abilities (and full setup randomize) pick how many within this range. Lock Count keeps the current card count instead.

Power growth types (tips)
  • Compounding — weak start; each rank multiplies toward late OP (S/SS/SSS).
  • Passive — always-on aura/trait; can still rank up; no activate cost.
  • Linear — steady +% or +check per rank; predictable.
  • Soft-cap — grows normally then slows hard after a mid rank until a breakthrough.
  • Breakthrough — plateaus until a story beat; then jumps.
  • Flat — fixed power; no rank ladder (talent/item lock).
  • Item-bound — grows only while the linked gear is worn/used.
